# Visual-JEV ninth-round evidence

From the extracted round-9 directory, use Python 3.12 and NumPy to run
selection.py, geometry_selection.py, arrow_analysis.py, arrow_effects.py and
prospective_analysis.py. Keep the included JSON outputs under new names before
rerunning. plot_round9.py regenerates the primary figure using Matplotlib.

The selection comparison and the prospective confirmation use the original
probe definitions. The prior geometry shift supplies labels only for family
selection. The independent confirmation render shares the procedural generator,
but was sealed after locking family and regularizer choices. The replay audit
compares every reconstructed readout with its previously stored predictions.
The arrow task uses independent images with full label-changing edits, exact
RGB histogram equality and matched local and background slot counts.

The archive includes images and all records for the statistics. The original
projection banks, model weights and GPU dependencies are kept in the original
runs, and the extraction and replay scripts document how those inputs were used.
